## 📌 Overview

**yourksatra-react-vite** adalah template website portfolio berbasis **React + Vite** yang dirancang sebagai **Single Page Application (SPA)** dengan tampilan modern, ringan, dan interaktif.  
Website ini berfungsi sebagai portofolio pribadi dan akan terus dikembangkan secara **open source** dengan berbagai fitur interaktif seperti animasi, game, dan showcase project dinamis.

✨ **Fitur utama saat ini:**

- Clean & Responsive UI
- Tema gelap & terang
- Animasi transisi smooth dengan Framer Motion
- Komponen modular & mudah dikembangkan
- Optimasi performa build menggunakan Vite
- Mini Game (Test Koran/ Kraepelin Test)

## 🧰 Prerequisites

Project ini membutuhkan:

- [Node.js](https://nodejs.org/) (v18 atau lebih tinggi)
- [NPM](https://www.npmjs.com/) atau [Yarn](https://yarnpkg.com/)
- Basic pengetahuan tentang React & JavaScript

---

## 🛠️ Installation

1. **Clone repository**

   ```bash
   git clone https://github.com/yourksatra/yourksatra-react-vite.git

   ```

2. **Masuk Ke Folder**
   ```bash
   cd yourksatra-react-vite

   ```

3. **Install dependencies**
   ```bash
   npm install

   ```
---

## 🚀 Usage

1. **Jalankan project secara lokal**
    ```bash
        npm run dev
    ```
    
2. **Lalu buka browser dan akses**
    ```bash
        http://localhost:5173
    ```
    
3. **Untuk build production**
    ```bash
        npm run build
    ```
